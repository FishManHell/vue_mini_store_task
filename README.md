# Vue Mini Store

Full-stack take-home: a mini e-commerce SPA for digital products (e-books, software licenses, online courses, templates) with product listing, details, and a persistent shopping cart.

Vue 3 + TypeScript on the frontend, FastAPI + Redis on the backend, all orchestrated by Docker Compose. See [`TASK.md`](./TASK.md) for the original assignment.

## Stack at a glance

| Layer    | Tech                                                                            |
| -------- | ------------------------------------------------------------------------------- |
| Frontend | Vue 3 + `<script setup>`, TypeScript, Vite, Pinia, Vue Router, Tailwind, PrimeVue |
| Backend  | Python 3.12, FastAPI, Pydantic v2, redis-py (asyncio), managed by `uv`          |
| Storage  | Static JSON catalog (in-memory) + Redis (cart, keyed by client session id)      |
| Infra    | Docker Compose — redis · backend · frontend (nginx)                             |

## Quick start (one command)

```sh
docker compose up --build
```

Then open:

- **App** — <http://localhost:8080> (nginx serving the SPA, proxying `/api/*` to the backend)
- **API** — <http://localhost:8000>
- **Swagger UI** — <http://localhost:8000/docs>

Stop with `docker compose down` (add `-v` to drop the Redis volume).

## How the pieces fit

```
┌──────────┐   /api/*       ┌──────────┐                ┌────────┐
│ Browser  │ ─────────────▶ │ frontend │  ────────────▶ │ backend│
│ :8080    │ ◀───── HTML ── │  nginx   │   /  (strip)   │  :8000 │
└──────────┘                └──────────┘                └────┬───┘
                                                             │
                                                             ▼
                                                        ┌────────┐
                                                        │ redis  │
                                                        │  :6379 │
                                                        └────────┘
```

- The product catalog is a static JSON file loaded once at backend startup.
- The cart lives in Redis under `cart:{session_id}` with a sliding TTL. Identity is the `X-Session-Id` header, a UUID generated by the browser and stored in `localStorage`.
- Money is `Decimal` end-to-end, serialized as a JSON string (`"29.99"`) to avoid float drift on the client.
